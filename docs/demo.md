# Record the 46-difference demo

The README GIF is generated by `python scripts/record-demo.py` from a fresh run of the included fixture.

The demo uses synthetic data and a deterministic program. It shows 46 changed variables and ends with `FEATURE_CACHE` and `TZ`. Neither change makes the demo fail alone.

From the repository root, install the checkout and the GIF renderer, then generate the asset:

```bash
python -m pip install -e .
python -m pip install Pillow
python scripts/record-demo.py
```

The script also works when invoked by absolute path from another directory. It runs the actual README command:

```bash
envbisect diagnose --pass examples/demo/pass.env --fail examples/demo/fail.env -- python examples/demo/app.py
```

It captures the CLI's output, checks the expected fixture result, and draws those real lines into a dark terminal GIF. The command is visually wrapped across two lines for readability. The recording stops after both verification lines so the 46 count, the two variables, and the confirmed interaction remain visible together. A fixed 19.8-second timeline makes the result easy to read even when the command runs faster or slower on another machine. No private host path or environment value is rendered. If the CLI report changes, the script fails for review rather than silently generating an outdated GIF.

The output is `docs/assets/envbisect-demo.gif`. Review the generated asset before publishing it. The script requires Python 3.11 or newer, Pillow, and a local monospace font (Cascadia Mono, Consolas, Menlo, or DejaVu Sans Mono).

For a live terminal run, `sh scripts/demo.sh` and `./scripts/demo.ps1` remain available. They pause briefly before the command and hold the final result for 12 seconds. Keep `--verbose` off for published recordings; it can show command output from experiments.
